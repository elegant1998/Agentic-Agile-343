## Download and Install

All release ZIP files are published in the [`download/`](download/) directory. Download the latest
`Agentic-Agile-343-v*.zip` and extract it into the tool's `skills` directory.
The ZIP already contains the top-level `agentic-agile-343` directory. Do not nest or rename it.

### Codex

```bash
mkdir -p ~/.codex/skills
unzip -q download/Agentic-Agile-343-v*.zip -d ~/.codex/skills
```

### Claude Code

```bash
mkdir -p ~/.claude/skills
unzip -q download/Agentic-Agile-343-v*.zip -d ~/.claude/skills
```

### Cursor

```bash
mkdir -p ~/.cursor/skills
unzip -q download/Agentic-Agile-343-v*.zip -d ~/.cursor/skills
```

### WorkBuddy

```bash
mkdir -p ~/.workbuddy/skills
unzip -q download/Agentic-Agile-343-v*.zip -d ~/.workbuddy/skills
```

Restart the tool after installation. For project-local Skills, replace `~/.tool-name/skills` with the corresponding `.tool-name/skills` directory in the project.
