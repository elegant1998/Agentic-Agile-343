## 说明

意图图谱是 Agentic Agile 3-4-3 架构中的**宏观导航地图**。它不是线性的 Product Backlog，而是机器可解析的三维向量知识库。IO（意图主理人）通过多模态模糊注入（文本、草图、会议纪要），由系统自动构建。

当某一特定任务被澄清并准备执行时，系统从全局图谱中**冻结并裁剪**出一份极度收敛的**意图契约（Intent Contract）**，作为该次动作的唯一执行基准。

## 6. 从图谱到契约：裁剪关系

下图展示了从宏观意图图谱到单次任务意图契约的裁剪过程：

```mermaid
graph LR
    subgraph 宏观导航
        IG[意图图谱<br/>Intention Graph]
    end
    
    subgraph 裁剪机制
        CL[澄清对话<br/>Conversation-to-Contract]
    end
    
    subgraph 运行态切片
        IC[意图契约<br/>Intent Contract]
    end
    
    IG -->|"IO 发起任务<br/>系统裁剪相关节点"| CL
    CL -->|"冻结目标/非目标/成功标准"| IC
    IC -->|"驱动"| EXEC[SCOPE-V 执行循环]
```

### 裁剪规则

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1 | IO 提出模糊意图 | 自然语言描述 |
| 2 | 系统从图谱检索相关节点 | 候选上下文集合 |
| 3 | 澄清对话：确认目标、非目标、边界 | 确定性阈值达标 |
| 4 | 冻结并裁剪 | **Intent_Contract.md** |
| 5 | 签署后进入 SCOPE-V 循环 | 任务执行 |

### 裁剪示例

| 意图图谱节点 | 裁剪到意图契约的位置 |
|-------------|---------------------|
| 战略北极星 → | §1 背景与目标 |
| 硬性约束 → | §2 非目标 + 约束矩阵 |
| 业务图谱 → | §3 输入输出契约 + §4 业务规则 |
| 用户画像 → | §4 边界条件 |
| 历史上下文 → | §6 未决事项与假设 |
